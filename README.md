# Digital Design & Verilog Learning

A personal learning repository for digital logic design, SystemVerilog/Verilog, RTL design, and computer architecture.

This repository records my notes, exercises, and small projects while studying digital hardware design, with a focus on building a solid foundation for future work in areas such as digital IC design, FPGA, computer architecture, and hardware-software co-design.

## Sources & Textbooks

### Main Textbook

**Digital Design and Computer Architecture: RISC-V Edition**  
Sarah L. Harris and David Harris

- Publisher: Morgan Kaufmann / Elsevier
- ISBN: 978-0-12-820064-3
- ScienceDirect: https://www.sciencedirect.com/book/9780128200643/digital-design-and-computer-architecture

The textbook is used as the main reference for:

- Digital logic
- Combinational logic
- Sequential logic
- SystemVerilog
- RTL design
- Digital building blocks
- RISC-V architecture
- Microarchitecture
- Memory systems

### Official Companion Resources

The official companion materials for the textbook include:

- Lecture slides
- HDL source code
- Laboratory exercises
- Figures
- Additional chapters and appendices
- Selected exercise solutions
- Official video lectures

Companion website:

https://pages.hmc.edu/harris/ddca/ddcarv.html

### Practice Resources

**HDLBits**

https://hdlbits.01xz.net/wiki/Main_Page

HDLBits is used for short Verilog/SystemVerilog exercises covering:

- Basic HDL syntax
- Combinational logic
- Sequential logic
- Finite state machines
- Digital circuits
